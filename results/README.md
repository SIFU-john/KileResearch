# Results

Raw experiment outputs for each article, one file per part: `NN-short-name.md`. Each log records the hardware, software versions, settings and the exact output, so anyone can compare their numbers with ours.

Start from [`templates/results-log.md`](../templates/results-log.md).

## Week 1

Week 1 (Parts 1–4) was run before this repo existed. Its measured outputs are reproduced inside each article, and the test rig is listed in the [hub README](../README.md). Separate raw log files for Week 1 weren't kept. From Week 2 on, every article has a results log here.
